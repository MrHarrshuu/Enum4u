\# Contributing to Enum4u



Thank you for your interest in contributing to Enum4u.



Enum4u is a unified security assessment framework designed for authorized security testing, research, education, and defensive security assessment.



\## Before Contributing



Please make sure your contribution:



\- Is related to the project's security assessment purpose.

\- Does not intentionally introduce malicious behavior.

\- Does not expose credentials, API keys, tokens, or private information.

\- Does not weaken existing security controls without a documented reason.

\- Includes tests for new functionality where practical.

\- Preserves existing functionality unless the change intentionally modifies it.
